# 15-AI - AI Architecture Specifications

## Purpose
This document specifies the AI Architecture of the Financial Operating System (FOS) / Artha, detailing the Knowledge Base, Recommendation Engine, Planning Engine, Forecast Engine, Prompt Strategy, and Context Management.

## Scope
Covers all offline-first AI calculations, prompt formatting templates, context windows serialization, and trajectory projections.

## Definitions
*   **Context Serialization:** Parsing database state and user configurations into a text template injected into the prompt.
*   **Monte Carlo Simulation:** A forecasting technique modeling future wealth curves under variable market return distributions.

## Responsibilities
*   Maintain local-first data privacy during AI processing.
*   Provide non-modifying financial recommendations.

## Relationships
*   Consumes data from the Database Design tables (assets, liabilities, settings).
*   Feeds optimization alerts to the Screen Specifications (Dashboard alerts panel).

## AI Architecture Components

### 1. Knowledge Base
*   **Contents:** Indexes local markdown documentation (`docs/*`), database schemas, and category definitions.
*   **Search Pipeline:** Embeds documents locally using a lightweight semantic search parser, allowing the AI to answer context-aware queries about user policies.

### 2. Recommendation Engine
*   **Inputs:** Active account transactions, card programs rules, lender interest rates.
*   **Logic:** Executes comparison passes. For instance, when a transaction occurs, the engine maps the billing merchant to reward multipliers and suggests optimal cards.

### 3. Planning Engine
*   **Inputs:** Outstanding debts, EMIs, target goal milestones, salary budget margins.
*   **Logic:** Generates step-by-step payoff schedules. It compares debt yields (mortgage rate) against investment projections to decide if surplus cash should prepay loans or purchase assets.

### 4. Forecast Engine
*   **Inputs:** Active asset balances, monthly savings configurations, expected interest rates, and inflation targets.
*   **Logic:** Projects net worth 30 years into the future. It adjusts growth rates by inflation:
    $$R_{\text{real}} = \frac{1 + \text{Nominal Return}}{1 + \text{Inflation}} - 1$$
    It simulates 1,000 Monte Carlo variations of returns to render a shaded probability distribution band of future net worth.

## Prompt & Context Strategy

### System Prompt Template
```
You are the Artha AI Wealth Coach. You operate strictly offline.
You do NOT modify user data directly. You draft recommendations.
Always prioritize debt reduction when interest rates exceed 8%.
Format all responses in markdown. Refer to active User Configuration settings.
```

### Context Management
To prevent token-limit failures, context payloads sent to local models are structured dynamically:
*   **Level 1 (Core):** Account balances, configurations, recent transactions (last 30 days). *Always injected.*
*   **Level 2 (Reference):** Active loan amortization schedules, reward program rules. *Injected only on request.*
*   **Level 3 (Archive):** Old transaction logs. *Excluded; summarized into monthly averages.*
